Backup / Restore библиотеки

Экспортирует именно сохранённую библиотеку профиля. Для несохранённых изменений сначала нажмите «Сохранить библиотеку» на основной странице.

Готово.

Восстановление сохраняет ID, даты, источники, status и SHA-256. Совпадающая запись пропускается. Один ID с другим содержимым блокирует всё восстановление. Ничего не записывается до отдельной кнопки «Применить» и подтверждения.

После успешного восстановления перезагрузите уже открытые вкладки библиотеки. Скачанный JSON содержит приватный текст; храните его как приватный файл.
