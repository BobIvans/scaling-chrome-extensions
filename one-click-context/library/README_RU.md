# Библиотека 0.4.0

Откройте меню значка → «Библиотека документов по датам» либо ссылку в просмотрщике.
Добавьте последний снимок, повторите после сбора другого чата. Добавляйте файлы вручную.
Выберите документы, фильтруйте дату добавления UTC, скопируйте или скачайте общий TXT/JSON.
Агрегированный TXT содержит подписи источников; экспорт исходного снимка в просмотрщике остался отдельным.

Обработка локальная. В памяти вкладки библиотека временная; «Сохранить библиотеку на компьютере» создаёт одну копию в localStorage профиля после согласия. Перезапуск/перезагрузка до сохранения теряет временную библиотеку. Общий JSON включает текст и метаданные, но не исходные байты; автоматическое восстановление библиотеки из JSON ещё не реализовано. Импорт JSON читает его как текст.

Лимит файла, текста и сериализованной библиотеки — 2 200 000 байт; массив исходных байтов тоже учитывается в записи, поэтому для больших TXT предел библиотеки может наступить раньше. ZIP: 300 элементов, 8 MiB распаковки, вложенность 2. Это отдельный бюджет распаковки, а не увеличение предела снимка. Нет скрытого усечения.

TXT/код/CSV/JSON UTF-8 сохраняют исходные байты, в том числе BOM/CRLF. DOCX извлекает основной текст документа, PPTX — текст слайдов по порядку, XLSX — значения и сохранённые результаты формул, PDF — имеющийся текстовый слой. Нет OCR, аудиораспознавания, старых бинарных DOC/PPT/XLS, исполнения макросов, извлечения всех вложенных объектов или гарантии сохранения таблиц/форматирования. Конвертация не делает PARTIAL полным.

Вложения сайтов надо скачать через сам сайт и импортировать. Автоматический обход всех документов всех чатов, DeepSeek-адаптеры, передача в каналы, торговые операции, мост OpenClaw и AI API не реализованы. Сохранённые чаты не превращаются в инструкции агенту автоматически.

Экспериментальный WebMCP: в поддерживающем браузере зарегистрированы read_collection_counts и read_selected_collection_txt. Второй требует подтверждения передачи выбранного текста. Это не авторизация Codex/OpenClaw и не AI backend. Регистрация и вызовы через реальный агентный WebMCP-контекст пока не проверены.

Зависимости vendored: fflate 0.8.3, pdfjs-dist 4.10.38. Лицензии в vendor. Код pdf.js не выполняет захваченные скрипты. Сборка под Chrome 116 сохраняет прежние разрешения; установка и PDF worker в настоящем Chrome требуют ручной проверки.
