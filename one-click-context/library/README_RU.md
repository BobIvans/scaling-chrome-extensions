# Библиотека 0.13.0

Откройте меню значка → «Библиотека документов по датам» либо ссылку в просмотрщике.
Добавьте последний снимок, повторите после сбора другого чата. Добавляйте файлы вручную.
Выберите документы, фильтруйте дату добавления UTC, скопируйте или скачайте общий TXT/JSON.
Агрегированный TXT содержит подписи источников; экспорт исходного снимка в просмотрщике остался отдельным.

Обработка локальная. В памяти вкладки библиотека временная; «Сохранить библиотеку на компьютере» создаёт одну копию в localStorage профиля после согласия. Перезапуск/перезагрузка до сохранения теряет временную библиотеку. Общий JSON включает текст и метаданные, но не исходные байты; автоматическое восстановление библиотеки из JSON ещё не реализовано. Импорт JSON читает его как текст.

Лимит файла, текста и сериализованной библиотеки — 2 200 000 байт; массив исходных байтов тоже учитывается в записи, поэтому для больших TXT предел библиотеки может наступить раньше. ZIP: 300 элементов, 8 MiB распаковки, вложенность 2. Это отдельный бюджет распаковки, а не увеличение предела снимка. Нет скрытого усечения.

TXT/код/CSV/JSON UTF-8 сохраняют исходные байты, в том числе BOM/CRLF. DOCX извлекает основной текст документа, PPTX — текст слайдов по порядку, XLSX — значения и сохранённые результаты формул, PDF — имеющийся текстовый слой. Нет OCR, аудиораспознавания, старых бинарных DOC/PPT/XLS, исполнения макросов, извлечения всех вложенных объектов или гарантии сохранения таблиц/форматирования. Конвертация не делает PARTIAL полным.

Вложения сайтов надо скачать через сам сайт и импортировать. Автоматический обход всех документов всех чатов, DeepSeek-адаптеры, передача в каналы, торговые операции, мост OpenClaw и AI API не реализованы. Сохранённые чаты не превращаются в инструкции агенту автоматически.

Push-to-talk на этой странице открывает только микрофон и только после явного
удержания кнопки. Запись ограничена 60 секундами и 16 MiB, хранится в памяти
вкладки и скачивается только отдельной кнопкой. Транскрипт редактируется вручную,
имеет лимит 16 000 UTF-8 байт и не передаётся в goal/router/queue. Browser Web
Speech, облачный ASR и автоматическая отправка audio не используются. Реальный
микрофон/разрешение Windows Chrome ещё требуют device qualification.

Форма Codex handoff теперь создаёт строгий `occ.goal-proposal.v1`: цель,
constraints, prohibition labels, нулевой provider budget и один parallel slot.
Все поля обязательны; неоднозначные отрицания и неверные типы отклоняются без
усечения. Локальная проверка proposal ничего не отправляет и не даёт action
authority. Настоящий запуск остаётся отдельным trusted click + confirm.

Кнопка «Предложить маршрут Laya» локально проверяет тот же канонический proposal
и возвращает один из четырёх advisory-маршрутов: анализ выбранного контекста,
создание job-артефактов, просмотр зарегистрированного действия или ручная
проверка. Prohibition labels не становятся положительными запросами. Router не
меняет mode, не вызывает Native Host/очередь/сеть и не выдаёт execution authority;
даже `confidence_milli=1000` требует отдельного доверенного действия.

`browser-action-contract.mjs` — отдельный fail-closed контракт между доверенным
UI и будущим browser transport. Grant живёт не более 30 секунд, хранится только
в памяти и связывает одно из пяти фиксированных capture-действий с точными
`tab_id`, `document_id` и каноническим HTTP(S) origin. Plan принимает только
`grant_id` и `request_id`: страница не может подменить action, handler, selector,
URL или options, а её текст помечен `DATA_ONLY`. Trusted UI/Escape cancel
терминален. Этот модуль не вызывает `chrome.*`, не нажимает элементы и всегда
возвращает `transport_qualified=false`, `dispatch_allowed=false`; реальный
установленный Chrome transport остаётся отдельной квалификацией.

Ссылка «Квалификация установленного transport» открывает локальную страницу,
которая по одному trusted click запрашивает optional `nativeMessaging`, сверяет
каждый файл с `PACKAGE_IDENTITY.json`, делает два независимых handshake с exact
extension ID/version/package-tree SHA-256 и затем отзывает разрешение. Одинаковый
host session ID, stale/wrong nonce, несовпавший файл/hash или неуспешный revoke
дают BLOCKED. PASS ничего не запускает и после проверки оставляет
`nativeMessaging` отозванным. Реальный PASS требует установленного Windows Chrome
и подготовленного host; репозиторные mocks его не заменяют.

Экспериментальный WebMCP: в поддерживающем браузере зарегистрированы read_collection_counts и read_selected_collection_txt. Второй требует подтверждения передачи выбранного текста. Это не авторизация Codex/OpenClaw и не AI backend. Регистрация и вызовы через реальный агентный WebMCP-контекст пока не проверены.

Зависимости vendored: fflate 0.8.3, pdfjs-dist 4.10.38. Лицензии в vendor. Код pdf.js не выполняет захваченные скрипты. Сборка под Chrome 116 сохраняет прежние разрешения; установка и PDF worker в настоящем Chrome требуют ручной проверки.
