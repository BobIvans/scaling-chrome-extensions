Проверка установленного канала.

Один доверенный клик сверяет каждый файл пакета, выполняет два независимых native handshake и отзывает optional nativeMessaging. Никакое browser action или AI-задание не запускается.

Проверка ещё не запускалась.

PASS относится только к текущему установленному extension ID/version, package-tree SHA-256 и native host. После PASS разрешение nativeMessaging удалено; для обычного подключения Chrome спросит его снова.
