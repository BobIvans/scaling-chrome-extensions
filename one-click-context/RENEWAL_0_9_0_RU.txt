WINDOWS RENEWAL
Use one-click-context/scripts/renew_windows.ps1 only after checking the actual Loaded from folder. The script backs up the folder first, requires explicit YES, downloads the pinned 0.9.0 runtime, verifies manifest version, copies only known runtime files, and restores backup on error.
