# Локальная автоматизация OCC и Laya

Первый полезный маршрут — выбранные источники → локальные обработчики → два документа и диагностический отчёт. Для него достаточно правил и существующих CLI. Laya можно подключить после проверки обработчиков. OpenAI API является отдельным необязательным профилем с расходами на API.

## Состояние на 1 октября 2026 года

- Ветка `renewal/occ-1.0-agent-relay` и PR #7 остаются основой интеграции.
- [PR #8](https://github.com/BobIvans/scaling-chrome-extensions/pull/8) добавляет отдельный `runProjectToolLoop` для native Responses function calls. Он не подключён к интерфейсу OCC.
- В PR #8 локально прошли 18 тестов `agent-core.test.mjs`: 5 существующих и 13 новых. Использовались фикстуры, без платного API и настоящей Laya.
- Устойчивый worker, документные handlers, адаптер бота и локальная ASR ещё требуют реализации и проверки.

## Профили

`local_rules` выполняет импорт, поиск, шаблоны и разрешённые команды без модельного API. `local_laya` добавляет локальный inference после установки модели. Загрузка зависимостей и весов, память, скорость и стоимость оборудования проверяются отдельно.

`openai_assisted` использует API и требует бюджета, проверки перед каждым запросом и учёта фактического usage. Наличие подписки ChatGPT не означает бесплатный обычный API-ключ. Модуль PR #8 ограничивает число запросов и вызовов; денежный лимит должен обеспечить его вызывающий runtime.

Laya выбирает известное действие. Генерацию нового Web3-кода выполняет отдельный coding executor. Если его нет, результатом является задание с контекстом. Диагностический успех не означает готовность бота к торговле.

## Следующий проверяемый результат

Команда «обновить документы и проверить проект» получает job ID, создаёт документы из выбранных источников, запускает зарегистрированную диагностику и сохраняет причины блокировки. У каждой операции есть отдельный результат. Частично выполненная задача не объявляется полностью завершённой.

Первый runner должен проверить доступность обработчиков, обеспечить аутентификацию локального bridge и origin, ограничить scope, поддержать отмену и возврат того же job по idempotency key. До этого нельзя обещать работу после закрытия браузера или автоматическое восстановление.

Контракт существующего модуля: [PROJECT_TOOLS_CONTRACT_RU.md](PROJECT_TOOLS_CONTRACT_RU.md).
