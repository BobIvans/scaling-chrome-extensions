ONE CLICK CONTEXT 0.3.0 — УСТАНОВКА И ОБНОВЛЕНИЕ

ВАЖНО ПЕРЕД ОБНОВЛЕНИЕМ С 0.2.0
1. Если старый временный session-снимок важен, сначала откройте просмотрщик
   установленной версии и скачайте его. Reload расширения может удалить временные
   данные; версия 0.3.0 не обещает восстановить уже утраченный снимок 0.2.0.
2. Распакуйте ZIP в постоянную отдельную папку.
3. Откройте chrome://extensions, включите «Режим разработчика».
4. Для обновления существующей установки замените файлы в её папке и нажмите
   «Обновить»/Reload только после экспорта важного старого session-снимка.
   Для новой установки нажмите «Загрузить распакованное расширение» и выберите
   папку, где manifest.json находится непосредственно в корне.

РАЗРЕШЕНИЯ
Расширение остаётся Manifest V3 и работает локально. Новое разрешение downloads
нужно только для начатого пользователем скачивания выбранного снимка и наблюдения
за состоянием именно этой загрузки. Расширение не читает и не меняет посторонние
загрузки. Нет all_urls, clipboardRead, history, cookies, debugger или серверов.

ИСПОЛЬЗОВАНИЕ
• Нажатие значка по-прежнему собирает страницу и пытается скопировать текст;
  повторное нажатие или Escape отменяет текущий сбор.
• После успешного непустого сбора уведомление содержит «Скачать TXT», «Просмотр»
  и «Закрыть». PARTIAL скачивается без скрытого повторного сбора, но остаётся PARTIAL.
• Меню значка → «Скачать последний собранный текст» работает после закрытия
  исходной вкладки, пока снимок есть в session или был явно сохранён.
• В просмотрщике кнопка «Сохранить последний снимок после перезапуска» после
  предупреждения создаёт единственную копию в chrome.storage.local. По умолчанию
  постоянная запись не выполняется.
• «Удалить сохранённый текст» удаляет session/local данные расширения, но не уже
  скачанные файлы и не системный буфер обмена.

Chrome сам применяет настройку запроса места сохранения и политики загрузок.
Сообщение «загрузка начата» не означает, что файл уже записан: дождитесь завершения
Chrome. При совпадении имён используется новое уникальное имя, без перезаписи.

СБОРКА CHROME-READY ZIP ИЗ ИСХОДНИКОВ
Из корня репозитория выполните:
  ./one-click-context/scripts/package_chrome_ready.sh

По умолчанию архив создаётся как
  dist/ONE_CLICK_CONTEXT_CHROME_READY_0.3.0.zip
и автоматически проверяется: manifest.json и INSTALL_RU.txt должны находиться
непосредственно в корне ZIP. Каталог dist и все ZIP исключены из Git.

Чтобы сохранить архив вне репозитория, передайте каталог первым аргументом:
  ./one-click-context/scripts/package_chrome_ready.sh /tmp/occ-artifacts
