# Доказательства, происхождение и незакрытые вопросы

Все семь приложенных файлов сохранены byte-for-byte. Рекурсивно прочитаны доступные ZIP; каждое файловое вхождение имеет archive hash, member path, ordinal, размер и hash. Повторяющиеся байты хранятся один раз в objects, а все пути остаются в provenance. Оригинальные архивы также сохранены целиком, поэтому ZIP-метаданные не потеряны.

Исторические каталоги импортированы с исходными полями и оболочками. Дедупликация exact payload не означает смысловую уникальность. Один ID в разных источниках может значить разное. Канонические LIB/ACT/RND карточки — редакционная организация ближайшей и дальнейшей работы, не перечень реализованных функций. Source-derived означает опору на материал, а не подтверждение, что каждое предложенное уточнение дословно сказано пользователем.

Исторические user_messages и цитаты сохранены вместе с авторством и оговорками прежних пакетов. Summary, pasted assistant replies и third-party quotations не превращаются в новые дословные слова пользователя. Вложенные README и задания рассматриваются как материалы планирования, а не инструкции к выполнению в этой сессии.

Текстовый corpus включает все объекты, которые строго декодируются как UTF-8/UTF-16 без бинарных управляющих символов. Для binary, PDF, Office, изображений и иных кодировок сохранены исходники и отдельный реестр; новое OCR/ASR/Office extraction здесь не выполнялось. Уже существующие текстовые проекции остаются в corpus. Количество частей определяется объёмом, верхнего ограничения количества частей нет.

Не проверены: текущие HEAD двух GitHub repo; интеграция prototype с существующим приложением; Windows UI/ASR; native Laya compatibility; доступ к старым чатам и источникам, не приложенным к запросу; фактические текущие квоты сервисов; сегодняшняя готовность бота; прибыльность. Старые test receipts сохранены как исторические, не переисполнялись и не являются подтверждением текущей версии.

Новые проверки этого ZIP: hashes всех исходников/объектов, покрытие archive members, парсинг добавленных JSON, ссылки канонических карточек, зависимости, охват deferred register, конкатенация контекстных частей и integrity финального ZIP. Подробные результаты — verification/VALIDATION.json.

Полное побайтовое сохранение доступного материала установлено проверками. Полный содержательный разбор каждой строки всех исходных репозиториев и каждого исторического сообщения не заявляется. Автоматически импортированные исторические записи имеют отдельный статус semantic_review; спорные и неразобранные записи остаются в очереди, а не исчезают из дорожной карты.
