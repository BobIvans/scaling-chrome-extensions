# Attachment Transport Ladder

1. Provider-native Files/image/document API — preferred when authorized.
2. Structured site tool / WebMCP.
3. Browser protocol / CDP exact file input.
4. Qualified AI-site attachment adapter with attachment-control fingerprint and independent readback.
5. Exact Windows file-picker fallback.

Rules:
- only explicitly selected artifacts leave the device;
- no directory-wide implicit upload;
- secret/private-key/seed files are blocked;
- upload receipt is stored;
- sending the message is a separate effect;
- text + attachment digests are bound into send-once reconciliation.
