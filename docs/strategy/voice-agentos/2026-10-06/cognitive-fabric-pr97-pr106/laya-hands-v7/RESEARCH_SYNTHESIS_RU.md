# Research synthesis

WebMCP: structured site tools improve reliable agent actuation.
Stagehand: use AI on unfamiliar pages, cache repeatable actions and run without LLM inference until drift.
agent-browser: compact accessibility snapshots and structural deltas reduce observation cost.
Computer-Using World Model: comparing expected next UI states before execution can improve action choice.
WeaveBench: long-horizon GUI+CLI+code tasks remain hard; trajectory-aware verification matters.
xAI: current Files APIs and mixed chat inputs support genuine text+file+image TaskPackets.
OpenAI: Sign in with ChatGPT can provide eligible plan-backed Responses API use to authorized local/open-source apps, but not access ChatGPT conversation history.

Conclusion: exact evidence → minimal multimodal TaskPacket → strong cognition → local critic/action compiler → real-world verifier → cached procedure.
