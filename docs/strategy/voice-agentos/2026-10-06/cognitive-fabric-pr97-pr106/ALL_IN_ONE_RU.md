# Authenticated Web3 Research Shadow

Read-only research over web3 apps the user legitimately accesses in their own browser.

Never bypass wallet authentication, extract keys/seed phrases, fabricate signatures, silently approve wallet prompts or submit transactions. Wallet approval/transaction submission is a separate high-consequence capability disabled by default.

Flashloan research may discover pools/routes, capture liquidity/fee/slippage displays, compare UI quotes with API/RPC evidence, capture protocol docs and wallet-gated dashboards. Final feasibility remains independently verified by RPC/simulation/paper layers.

## FILE: `COGNITIVE_FABRIC_ARCHITECTURE_RU.md`

# Cognitive Fabric Architecture

## CognitiveProvider
Fields: provider_id; transport (deterministic/local/service/SIWC/API/CLI/ACP/browser); modalities; tools/search/code support; max context; latency/cost/quota/privacy; reliability by TaskClass; health; auth profile; session capabilities.

## CognitiveRequest
role (ROUTER/RESEARCHER/STRATEGIST/CODE_ENGINEER/CRITIC/VISION/SUMMARIZER); GoalContract excerpt; active subgoal; JIT ContextPack; bounded question; allowed tool IDs; output schema; token/latency budget; prohibited effects; evidence refs.

## CognitiveProposal
May contain conclusions, hypotheses, requested evidence, semantic action proposals, searches, code changes, uncertainty/confidence, verifier suggestions, citations/artifacts. It never directly grants effects.

## Session state
provider/account/workspace/conversation/session; role; last ContextPack; last accepted turn; pending request; result artifact; coverage; stall/failure; quota/usage.

## Idle intelligence
Cheap idle cycles may dedupe/tag, reconcile temporal facts, detect stale summaries, compile procedures, prefetch likely context and update reliability priors. They never auto-promote code/capabilities without replay/canary evidence.

# Grok Build / ChatGPT / API Session Relay

## Grok Build
Prefer native CLI/headless/ACP for code/workspace tasks: launch in exact registered workspace, use browser-auth session or scoped xAI API key, persist session identity, ingest plans/tools/logs/artifacts, and keep Core resource/effect gates authoritative.
Support Grok web Build Mode as a persistent visual/build conversation surface when continuity in the browser matters.

## ChatGPT
Support official Sign in with ChatGPT for eligible open-source/local applications when the user explicitly authorizes plan usage. This is a cognitive provider; it does not grant access to ChatGPT conversation history/memory. Local Library remains context authority.
Fallbacks: ordinary API profile (separate billing), browser ChatGPT session for a specific existing thread, or local model.

## Relay protocol
choose role → build bounded ContextPack → choose session → send → observe completion → archive raw answer → extract CognitiveProposal → verify artifacts/citations where applicable → compile next local action → if needed send only delta + unresolved gaps.

## FILE: `LAYA_RAILWAY_V5_RU.md`

# Laya Railway V5 — Cognitive Escalation + Next-Action Prediction

The Railway asks:
1. Is the next edge deterministic?
2. Is exact local evidence enough?
3. Can Laya/small local model classify it?
4. Is there a cached qualified procedure?
5. Is a strong model actually needed?
6. Which provider best matches modality/context/latency/quota/cost/privacy?
7. What is the smallest ContextPack it needs?
8. Did its proposal add evidence/actionable semantics?
9. Can the discovered route be compiled into a reusable low-cost capability?

DecisionState includes Goal/acceptance gap, H2/H1/H0, HorizonGraph subgoal, blocking uncertainty, context freshness/debt, SurfaceGraph, deterministic capabilities, procedures, ProviderGraph, active AI sessions, quota/usage, difficulty, modality, risk, latency/money/plan budgets, progress velocity, recent failures and human interruption budget.

P0 Need kind: FACT / SURFACE_STATE / TOOL / PLAN / CODE / VISUAL_UNDERSTANDING / USER_INTENT / AUTHORITY / VERIFICATION.
P1 Cheapest resolver: DETERMINISTIC_RULE / LIBRARY / PROCEDURE / LAYA / LOCAL_MODEL / SUBSCRIPTION_MODEL / GROK_BUILD / API_MODEL / HUMAN.
P2 Provider fit: TaskClass, modality, context fit, historical success, latency, quota, marginal cost, privacy.
P3 Context request: exact evidence subset only.
P4 Proposal critic: bounded question answered? grounded? executable semantic action? GoalContract respected? cheaper route better?
P5 Disposition: COMPILE_ACTION / STORE_EVIDENCE / ASK_FOLLOWUP / ESCALATE / DISCARD / BUILD_CAPABILITY.
P6 Learn cost: recurring model-discovered action should become cached procedure/capability.

Strong model escalation is justified only when expected gain in verified progress/success exceeds latency + monetary/plan cost + quota opportunity cost + privacy/risk.

## FILE: `MASTER_CONTEXT_RU.md`

# Master Context — Cognitive Fabric

## Target experience
The user can say: “Continue flashloan qualification; gather context from my Library, prior AI chats, Drive, web3 dashboards and repo; ask Grok/ChatGPT/Codex only when useful; run safe commands/tests/simulations; save all evidence; improve AgentOS or Studious Pancake if needed; keep going until acceptance is proven.”

AgentOS coordinates local Library, browser/Windows surfaces, user-authorized web research, Grok Build CLI/ACP or web session, ChatGPT-plan usage when officially authorized, ordinary APIs, local models, code workers, terminal/process capabilities and the Studious Pancake qualification runtime.

## Reimagination
System-2 is no longer one opaque escalation route. The app has three fabrics:
1. Context Fabric — raw evidence → events → temporal graph → JIT ContextPack.
2. Action Fabric — WebMCP/API/CDP/DOM/AX/UIA/terminal/repo/process/domain capabilities.
3. Cognitive Fabric — deterministic rules → Laya/small local models → local LLM/VLM → ChatGPT-plan/Grok → paid APIs → optional high-value quorum.

A provider receives a bounded CognitiveRequest and returns a non-authoritative CognitiveProposal. The canonical Goal remains local.

## Cost principle
Do not pay for intelligence to do what exact code already knows. After AI discovers a stable workflow:
AI discovery → semantic recipe → replay/canary → registered capability → future zero/low-LLM execution until drift.

## External AI sessions
Grok/ChatGPT sessions are durable cognitive lanes with provider/account/workspace/conversation identity, last ContextPack, pending request, raw result artifact, quota/health and failure state. Their output is archived into Library and compiled into local action semantics.

## Self-renewal
GapSpec → existing capability search → Codex/Grok Build code worker → isolated worktree → tests → PR/CI/exact-head merge → stage/canary → capability registration → restart/reconnect → resume original Goal.

This wave extends PR64–PR96; it does not replace unfinished foundations.

Goal: the local AgentOS owns the durable goal, context, surfaces, effects and verification. Grok Build, ChatGPT-plan usage, APIs and local models are bounded cognitive providers invoked only when they add enough expected verified value to justify latency/cost/quota/privacy.

# Recovered older design ideas

Earlier discussions already contained the roots of this architecture.

- Personal AI OS / Notion replacement: linked local knowledge, auto-tagging/embeddings, RAG over conversations/notes/PDFs, local multi-agent debate. Modern owner: Project Capsule + Temporal ContextGraph + JIT ContextPack.
- ZipWiz/model mesh: voice/text → distillation → router → parallel model roles → consensus/refinement → capability mining → append-only ledger. Modern roles: Harvester, Context Compiler, Code Worker, Strategist/Research Director, Independent Auditor, Library owner.
- Universal Context + Automation OS: ChatGPT/Grok/Gemini/Telegram/browser/GitHub/video/audio → labeled Library with goals/decisions/tasks/dependency graph and execution backends.
- Experimental stack previously discussed: screenpipe-like ambient capture, Graphiti-like temporal graph, Tree-sitter/Aider/SCIP repo maps, faster-whisper/Silero/Qwen ASR+embeddings, Docling, OpenHands, BrowserCode/CDP, UFO²/Windows automation, OmniParser/vision fallback, MCP, durable workflows, replay/canary and behaviour→skill compilation.
- One Click Context failure taught that visible DOM is not historical completeness; modern streamed archives retain coverage/gaps/order.

These ideas are now capability providers under canonical Library/Surface/Cognitive fabrics, not separate authorities/databases.
