# Authenticated Web3 Research Shadow

Read-only research over web3 apps the user legitimately accesses in their own browser.

Never bypass wallet authentication, extract keys/seed phrases, fabricate signatures, silently approve wallet prompts or submit transactions. Wallet approval/transaction submission is a separate high-consequence capability disabled by default.

Read preference: documented API → WebMCP/MCP/structured tool → user-authorized CDP network response → DOM/AX extraction → vision fallback.

Store origin, observable account/session identity, chain, selected market/pair/pool, freshness, URL, extraction route, payload/hash and coverage/warnings.

For useful data without stable API, build a read-only UI Data Adapter candidate, fixture/replay/canary it, then register it. Future runs reuse it without LLM until drift.

Flashloan research may discover pools/routes, capture liquidity/fee/slippage displays, compare UI quotes with API/RPC evidence, capture protocol docs and wallet-gated dashboards. Final feasibility remains independently verified by RPC/simulation/paper layers.
