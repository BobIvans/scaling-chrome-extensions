# Dual-Repo Self-Renewal Orchestrator

Targets: Voice AgentOS and Studious Pancake.

GapSpec → dormant capability search → choose Code Worker (Codex/Grok Build/other) → isolated worktree → patch → tests → diff audit → PR → exact-head CI → merge → staged release → device/canary qualification → capability registration → restart/reconnect → resume original Goal.
