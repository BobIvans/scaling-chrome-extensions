# Laya Execution Brain Architecture

The Brain is a local control system with small typed decisions. A strong model is one possible cognitive resource.

## Seven controllers
- **B1 Verified State** — only independently verified current state enters the active path.
- **B2 Goal Frontier** — reduce long goals to the smallest useful open acceptance/subgoal edge.
- **B3 Evidence/Memory** — select the smallest relevant mix of raw evidence, graph, events, procedures, failures and live state.
- **B4 Value Router** — estimate success, progress, information gain, latency, money/quota, human attention, risk and resource pressure; choose the cheapest route above the required success threshold.
- **B5 Parallel/Anytime** — launch independent safe lanes, consume first useful evidence immediately, cancel low-value work.
- **B6 Verifier** — every consequential step has process/outcome rubrics; provider “done” text has zero authority.
- **B7 Learning** — update empirical route/tool/provider/procedure priors from verified outcomes; promote stable discovered paths into cheaper deterministic procedures.

## Grok
Grok is a strategic lane for novel semantics, repeated verified failure, strategy contradiction and capability/code design. Its result is bound to a `world_revision`; stale advice is discarded.
