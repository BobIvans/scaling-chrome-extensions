# Multimodal Intelligence Broker

Vision is fallback where structured state cannot answer.

Route: DOM/AX/native structured state → local OCR/detection → tiny local VLM triage → stronger local VLM if available → ChatGPT-plan/OpenAI/xAI/other remote multimodal → optional high-value multi-model verification.

Persist image/frame artifact hash, task, detections/answer, pointing if available, confidence, model/provider/version, latency and provenance. Visual text never grants effect authority.
