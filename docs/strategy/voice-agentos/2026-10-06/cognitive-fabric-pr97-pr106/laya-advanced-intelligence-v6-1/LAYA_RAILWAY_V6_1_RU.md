# Laya Railway V6.1 — Nine Rails

Laya is a typed semantic controller, not an unrestricted agent.

## 1. GOAL
Choose the active observable acceptance gap. Detect goal drift and genuine human-intent ambiguity.

## 2. EVIDENCE
Decide what exact fact/context is missing, whether it is fresh, whether sources contradict, and whether a safe read can resolve the gap.

Evidence classes:
`EXACT | OBSERVED | TRUSTED_SECONDARY | MODEL_CLAIM | UNKNOWN`.

Model claims alone do not prove consequential postconditions.

## 3. SURFACE
Bind the exact account/workspace/tab/document/app. Prefer structured API/tool/CDP/DOM/AX routes. Detect human foreground ownership and shadow/background options.

## 4. RESOLVER
Choose the cheapest reliable tier:
`EXACT → FAST → STRONG → API_FALLBACK`.

Questions:
- registered capability/procedure already exists?
- Laya can decide among bounded candidates?
- strong reasoning/vision/code really required?
- provider/session has sufficient capability/quota?
- metered API justified?

## 5. PREFETCH
Predict the immediately likely next requirement and start only safe independent reads:
- repo symbols while a Drive file downloads;
- RPC health while route discovery runs;
- ContextPack while Grok reasons.

## 6. ACTION
Code generates bounded ActionCandidates. Laya chooses an ID or abstains.

Every candidate contains exact target, effect class, resources, expected outcome, verifier, and reconcile/rollback route.

## 7. VERIFY
Trust observed reality rather than provider text:
- postcondition observed?
- evidence quality sufficient?
- acceptance gap closed?
- any external effect still UNKNOWN?

## 8. RECOVER
Classify stale context, wrong surface, drift, missing capability, external/tool/strategy failure, UNKNOWN effect or missing human authority.
Reobserve before retry. Never blind-retry an unknown external effect.

## 9. LEARN
If the sequence was successful and repeatable, compile it into a replay-tested deterministic procedure with drift signals.

## Objective
Optimize **verified progress per unit of latency + cost + human attention + risk**.
