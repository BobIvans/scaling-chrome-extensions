# Research synthesis for V6.1

- **WebMCP:** structured website tools support choosing explicit tool schemas before visual clicking.
- **Stagehand:** current production philosophy is AI for unfamiliar workflows, deterministic code/caching for repeat workflows, and AI again on drift.
- **agent-browser:** accessibility snapshots, interactive filtering and deltas support compact structured browser state.
- **Magentic-UI:** co-planning, co-tasking, action guards and plan learning reinforce visible human-agent control.
- **LongHorizon-Harness:** fresh-context Manager/Executor/Auditor rounds reinforce durable verified state and independent auditing.
- **Agent skills failure research:** some reusable skills can reduce success or raise cost, so load the minimum relevant procedure/tool set.
- **OpenAI Sign in with ChatGPT:** eligible open-source/local apps can request explicit permission to use eligible ChatGPT plan usage; it does not provide conversation access.
- **Grok Build:** current TUI/headless/ACP and workflows make it suitable as a persistent code/research lane rather than only a browser tab.

The architectural conclusion is intentionally simple:
**structured state + bounded Laya decisions + exact execution + verification + procedure caching.**
