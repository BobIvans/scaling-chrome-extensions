# Universal Context + Web3 Research Flow

## Context harvesting
Permitted useful information should become durable local context:

browser pages → AI conversations → Drive API/UI → site downloads → local files → repo/logs → authorized web3 dashboards → external AI results.

Pipeline:
`observe/download → preserve raw artifact → hash/version/provenance → deterministic labels → structured extraction → optional FAST classification → relations → Library → ContextGraph → JIT ContextPack`.

Visible DOM is never assumed to equal complete historical context. Unknown MIME bytes are preserved even without a parser.

## Navigation/extraction priority
1. structured site tool / WebMCP;
2. official API/RPC;
3. CDP/browser protocol/network observations;
4. DOM/accessibility;
5. qualified site adapter;
6. Windows UIA;
7. visual fallback only when structured state is insufficient.

## Read-only web3 research
For user-authorized dashboards collect evidence such as:
protocol, chain, market/pool/pair, liquidity, fees, displayed quotes, route availability, timestamps, URL, observation route, raw payload hash, coverage/warnings.

Unknown dashboard:
`observe → strong intelligence only if necessary → propose read-only extractor → fixture/replay → canary → register`.

Future runs use the registered extractor without STRONG/API unless drift is detected.

Boundary:
no seed/private-key extraction, wallet-auth bypass, automatic wallet signature or transaction submission in this research profile.
