# Flashloan Workbench V6.1

Target local UI for Studious Pancake qualification:

- Qualification Goal / phase / acceptance;
- Terminal / Processes;
- Repo / Git Diff;
- Data Sources / RPC Health / DEX Aggregators;
- Web3 UI Evidence;
- Pair / Pool Explorer;
- Market Graph;
- Candidate Routes;
- Simulation / Replay;
- Paper Runs;
- AI Sessions;
- Evidence / Failures;
- Next Action;
- STOP.

Example:
“Continue qualification. Gather current evidence from configured APIs/RPC and my authorized web3 dashboards, update the pair/route graph, run simulation/paper checks, and use Grok/ChatGPT only for unresolved novel issues.”

Execution follows the nine rails:
`Goal → Evidence → Surface → Resolver → Prefetch → Action → Verify → Recover → Learn`.

Default qualification remains non-live. Live financial effects require a separately qualified capability.
