# Four-Level Intelligence Policy

## EXACT — no model call
Known browser/UI action, download/export, hash/dedupe/version, deterministic labels, registered commands/tests, replayed procedures, exact numeric comparisons, known web3 extraction adapters.

## FAST — Laya/local lightweight logic
Choose among bounded routes, classify missing context, rank evidence, select safe observation, decide whether escalation is necessary.

## STRONG — user-authorized strong intelligence
ChatGPT-plan usage, Grok Build/session or another configured strong provider.
Use for unfamiliar systems, hard synthesis, coding, novel strategy, difficult visual interpretation and repeated recovery.

## API_FALLBACK — metered provider API
Only when STRONG is unavailable/insufficient, an API-only feature is required, or task value justifies spend.

## Learning rule
If STRONG/API discovers a stable workflow:
`discover → semantic recipe → replay → canary → REGISTERED → future EXACT execution`.

Architecture never depends on a particular small model.
