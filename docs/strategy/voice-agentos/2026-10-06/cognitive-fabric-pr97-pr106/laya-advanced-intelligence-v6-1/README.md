# Laya Advanced Intelligence V6.1 — Simplified Railway

This revision supersedes the previous V6 implementation addendum.

The model zoo is intentionally removed from the architecture. Specific models are replaceable implementation details.

Four intelligence tiers only:
1. **EXACT** — deterministic code, cached procedures, registered tools.
2. **FAST** — Laya/local lightweight classification and ranking.
3. **STRONG** — user-authorized strong provider/session such as ChatGPT-plan or Grok Build.
4. **API_FALLBACK** — metered API only when cheaper tiers cannot meet the required reliability.

Universal railway:
`Goal → Evidence → Surface → Resolver → Prefetch → Action → Verify → Recover → Learn`
