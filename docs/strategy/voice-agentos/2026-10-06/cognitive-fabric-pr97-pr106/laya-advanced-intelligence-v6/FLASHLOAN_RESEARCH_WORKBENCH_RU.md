## Example voice command

“Research SOL/USDC and related routes across configured APIs and my authorized web3 dashboards; compare freshness and liquidity, update the evidence graph, run the current simulation/paper qualification, and ask Grok only if a novel route/protocol needs interpretation.”

## Workflow

1. Laya predicts missing need.
2. Zero-LLM data collectors/API/RPC run first.
3. Registered web3 UI adapters gather missing UI-only evidence.
4. Unknown dashboard semantics escalates to strong AI once.
5. Observations enter market/evidence graph.
6. Candidate engine proposes routes.
7. RPC verifies state.
8. simulator/replay/paper evaluates.
9. Auditor verifies.
10. failing code routes to Codex/Grok Build repair lane.
11. successful research workflow becomes a reusable experiment/procedure.

Default: no live trading.
