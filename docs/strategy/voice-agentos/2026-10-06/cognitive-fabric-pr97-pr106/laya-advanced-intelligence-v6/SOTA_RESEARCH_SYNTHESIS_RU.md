# SOTA research synthesis for Laya V6

## WebMCP
Chrome's WebMCP exposes site functions as structured tools with schemas. This should be the highest-priority browser action route when available.

## Stagehand
Stagehand's current design explicitly mixes AI discovery with deterministic code and caches/self-heals repeat actions. This is a strong confirmation of our `AI once → procedure many times` architecture.

## browser-use / CDP snapshots
Current browser-use code includes CDP DOMSnapshot processing for visibility/clickability/layout. This supports a structured observer before screenshots.

## Graphiti-style temporal memory
Current Graphiti ecosystem focuses on incrementally updated temporal graphs, bi-temporal facts, and hybrid semantic/keyword/graph retrieval. This matches our arbitrage evidence timeline and personal context graph.

## Grok Build
Current Grok Build can run TUI, headless or ACP; current xAI product materials describe subagents, skills, worktrees, web search, terminal execution, background tasks and workflows. It is therefore a better coding/deep-research lane through CLI/ACP than only browser clicking.

## ChatGPT-plan lane
Current OpenAI Sign in with ChatGPT allows eligible open-source/local apps, with explicit user authorization, to make eligible Responses API requests using a Plus/Pro plan allowance. It does not expose the user's ChatGPT conversations; Local Library must supply context. Ordinary API billing remains separate.

## Local vision
SmolVLM 256M/500M supports tiny local multimodal tasks. ScreenVLM focuses on structured screen parsing. Qwen3-VL-2B provides a stronger visual-agent tier. These should be benchmarked as fallbacks, not primary UI authority.
