# Notion-Class Context OS V6

The old Notion-competitor idea is expanded into an execution-aware local workspace.

## Project Capsule

A capsule links:
- conversations;
- Drive docs;
- downloaded artifacts;
- browser research;
- web3 observations;
- repo/files;
- decisions;
- failed attempts;
- experiments;
- AI sessions;
- procedures;
- missions;
- external data sources;
- timelines.

## Auto-organization without constant LLM cost

Layer 0 deterministic:
source, file type, URL, project mapping, timestamps, hashes, MIME, repo paths.

Layer 1 local ML:
embeddings, entity extraction, relation candidates, transcript.

Layer 2 Laya:
bounded project/category/status decisions.

Layer 3 strong model:
only ambiguous classification, synthesis or ontology expansion.
