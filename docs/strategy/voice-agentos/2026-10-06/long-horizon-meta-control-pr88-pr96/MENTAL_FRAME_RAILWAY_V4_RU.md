# Mental Frame Railway V4 — index

The meta-controller conditionally activates typed frames rather than running one monolithic prompt loop.

F0 Authority — effect/resource envelope.  
F1 Outcome — terminal state, remaining acceptance, anti-goals.  
F2 Reality — fresh independently verified state.  
F3 Uncertainty — largest blocking unknown.  
F4 Information Gain — observe/retrieve/ask based on value.  
F5 Horizon — active subgoal and independent branches.  
F6 Strategy Portfolio — materially different approaches when warranted.  
F7 Pre-mortem — bounded failure taxonomy + early warnings.  
F8 Resource & Parallel — safe concurrent lanes and one-writer resources.  
F9 Skill/Tool — minimal qualified capability set; negative-transfer guard.  
F10 Action — bounded code-generated ActionCandidates.  
F11 Counterfactual — predicted state delta / safer equivalent.  
F12 Commit — revalidate, lease, intent, dispatch once.  
F13 Verification — independent environment audit.  
F14 Progress/Credit — acceptance closure and evidence attribution.  
F15 Recovery/Pivot — local failure repair, reobserve, strategy switch.  
F16 Context Folding — raw evidence retained, completed history compressed.  
F17 Procedure Learning — reusable blueprint/trajectory after replay.  
F18 Termination/Audit — all acceptance verified, no unresolved UNKNOWN effects.

A long task should use many fresh-context verified rounds over one durable goal, not one ever-growing LLM conversation.
