# Laya Railway V3 — Perfect Fastest-Route Decision Layer
Laya is System-1 semantic routing, not shell/browser/effect authority.

## One-prompt behaviour
Human states the goal once. Internal rail repeatedly:
1. compiles/updates GoalContract;
2. resolves context gaps with safe reads;
3. identifies exact surface/identity;
4. generates bounded ActionCandidates;
5. selects the cheapest useful route;
6. invokes System-2 only for genuinely hard reasoning/capability design;
7. preflights consequential effects;
8. executes through a qualified executor;
9. verifies postcondition;
10. writes ProgressDelta/procedural memory and re-ranks.

## Human-question policy
Ask only when the answer changes the safe executable outcome.
Before interrupting: search trusted Library/preferences, inspect surface, perform reversible read, use System-2 for technical uncertainty.
Always expose one short bounded question + Other/Explain when: materially different terminal states remain; exact human target cannot be resolved; consent/credential is required; or an irreversible effect is outside the current envelope.

Approximate decision value:
P(success)×goal_value + information_gain + unlock_value − latency − cost − human_attention − risk.
This ranks candidates; it does not grant authority.

## Escalation
L0 deterministic/known capability → L1 local Laya typed decision → L2 procedural memory → L3 small planner → L4 high-capability System-2 → L5 capability build/repair → L6 human.
Fastest reliable lower level wins.
