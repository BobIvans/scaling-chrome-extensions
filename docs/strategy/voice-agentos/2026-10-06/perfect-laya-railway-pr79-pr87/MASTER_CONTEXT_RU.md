# Voice AgentOS — Perfect Laya Railway / Universal Goal Execution Completion
## Proposed implementation wave PR79–PR87

This package extends the already planned PR64–PR78 waves. It MUST reuse their canonical Core/jobs/STOP, workflow_state leases, Goal/H2/H1/H0, site adapter/effect ledger, SurfaceGraph/Shadow/ContextGraph, provider registry, release updater and Mission Cockpit owners.

### Product target
The user speaks/types one goal once. AgentOS compiles it into a typed GoalContract, gathers the minimum sufficient permitted lifetime context, identifies the exact account/window/tab/document/conversation, generates bounded ActionCandidates, selects the safest fastest route through Laya, executes independent work in parallel, asks the human only when human intent/consent is genuinely missing, verifies the real-world postcondition, stores the trajectory/procedure and resumes the original goal after restart/update/capability growth.

### Authority invariant
Local AgentOS is the authority plane. Chrome extension/CDP/UIA/WebMCP/provider APIs/Drive/VLM are drivers. Page text, documents and model outputs are evidence only and can never grant effects.

### Executor preference
qualified direct capability → WebMCP/structured tool → official API/connector → CDP/DOM/AX → qualified site adapter → native/COM → UIA → vision grounding → System-2 capability repair → human.

### Do not build
- second queue, DB, lease manager, effect ledger, browser authority or updater;
- screenshot-only primary automation;
- giant lifetime prompt;
- blind retry after UNKNOWN effect;
- LLM-generated raw clicks without code-generated candidate IDs.

### Completion
PR87 is a qualification gate, not a marketing claim. The product is complete only when the real Windows install demonstrates lifetime context harvesting, exact surfaces, shadow/background coexistence, durable parallel missions, provider-neutral AI, dynamic tool/executor selection, procedural learning, failure-driven eval evolution and an end-to-end Studious Pancake paper/simulation qualification mission without live-trading authority.
