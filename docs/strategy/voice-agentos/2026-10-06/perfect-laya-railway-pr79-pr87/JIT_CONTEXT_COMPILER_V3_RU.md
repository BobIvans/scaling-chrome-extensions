# JIT Context Compiler V3
Lifetime memory is local storage, not a prompt.
Memory tiers:
L0 exact raw evidence; L1 events; L2 semantic abstractions; L3 procedural memory; L4 task-specific JIT pack.

Retrieve by semantic relevance, exact entity/identity, temporal validity, goal relation, contradiction, procedural similarity, source reliability, freshness and prior success/failure.

Every compressed statement retains provenance. If full context succeeds and compressed context fails, diagnose omitted evidence, update compression guideline and canary it.

ContextPackV3 sections: GoalContract excerpt; acceptance gaps; exact target identity; fresh facts; contradictions; applicable procedures; surface capabilities; ActionCandidates; relevant failure edges; provenance refs.
