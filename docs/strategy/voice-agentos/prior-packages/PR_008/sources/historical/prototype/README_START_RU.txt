CONTEXT LIBRARY — ЛОКАЛЬНЫЙ ПРОТОТИП V2
====================================

Цель: за несколько действий получить проверяемый контекст всего Git-репозитория,
найти связанные файлы, добавить метки, описать задачу и передать пакет выбранному AI.
Это отдельный переносимый прототип, не установленное обновление SCE и не готовый
универсальный агент управления компьютером.

1. КАК ЗАПУСТИТЬ НА WINDOWS 11

Нужны Python 3.11 или новее с компонентом Tcl/Tk и Git в PATH.
Распакуй папку прототипа целиком, сохрани app.py и context_pipeline.py рядом.
Открой Launch_Windows.cmd. Launcher ничего не устанавливает, не запускает Laya,
не подключается к AI и не запрашивает API-ключи.

Альтернатива в PowerShell из папки прототипа:
    py -3 app.py

Linux/macOS с установленным Tkinter:
    python3 app.py

2. САМЫЙ КОРОТКИЙ РАБОЧИЙ МАРШРУТ

1) Выбери папку локального Git-репозитория.
2) Выбери папку библиотеки ВНЕ репозитория; например C:\Users\Ivan\ContextLibrary.
3) Нажми «Снять HEAD и разбить весь репозиторий».
4) Дождись завершения и проверь журнал/отчёт полноты снимка.
5) Просмотри группы связанных файлов, поиск и метки.
6) На вкладке «Задача → пакет для AI» укажи задачу и ChatGPT / Grok / Gemini.
7) Выбери весь снимок либо конкретные файлы; зависимости можно добавить к выборке.
8) Нажми «Собрать документ для AI», выбери папку результата вне репозитория.
9) Открой результат, прочти manifest и исключения. Передай пакет AI вручную.

Провайдер — адресат документа. Этот выбор не подключает аккаунт, чат или API.
Режим «Создать автоматизацию — проект» добавляет JSON-контракт с шагами,
зависимостями и критериями. Он НЕ запускает команды, не отправляет документы,
не проверяет GitHub merge и не является подтверждённым импортом Laya.

3. ЧТО ИМЕННО СОХРАНЯЕТСЯ

Снимок привязан к одному Git HEAD. Сохраняются tracked-файлы из этого commit,
исходные байты, пути, хеши, каталог и текстовые части. Изменённые и untracked-
файлы рабочего дерева не становятся содержимым HEAD: проверь backend-отчёт.
Для их анализа сначала создай подходящий commit самостоятельно либо используй
будущий отдельный режим захвата рабочей копии; UI не делает commit за тебя.

Связанные части строятся эвристически. Неразрешённые импорты, runtime-связи,
submodule/LFS и другие ограничения должны оставаться в manifest/отчёте backend.
Не считай группу файлов доказательством полноты архитектурной зависимости.

Предпросмотр показывает максимум 64 КиБ одного файла. Это ограничение просмотра,
а не потеря исходника. Полный снимок и multipart-экспорт не имеют потолка в 20 частей.
Количество частей определяется содержимым; типовой размер части — 256 КиБ.
Байт — не токен: допустимый объём загрузки зависит от выбранного AI.

Метки сохраняются отдельно от исходных байтов. Поиск работает по путям,
меткам и доступному тексту. Переключение снимка не изменяет предыдущий снимок.

4. ПРИВАТНОСТЬ И ПЕРЕДАЧА КОНТЕКСТА

Локальный снимок может содержать приватные данные. Экспорт должен просматриваться
до передачи внешнему AI. Возможные секреты backend исключает из share-проекции
с записью в реестр; это эвристика, а не гарантия удаления всех чувствительных данных.
Проверь manifest, список исключений и задачу. Не передавай сырые локальные
снимки автоматически. Журнал UI не записывает текст задачи или содержимое файлов.

5. ДОСТУПНОСТЬ И КЛАВИАТУРА

Tab / Shift+Tab — контролы; стрелки — каталог и вкладки.
Ctrl+F — поиск; Enter в поиске — выполнить поиск.
Ctrl+Enter — собрать пакет; F5 — обновить список снимков.
Для выбора нескольких файлов используй Shift/Ctrl вместе с выделением.
Для изменения меток выбери один файл и введи метки через запятую.

UI использует стандартные Tkinter/ttk-элементы и текстовые подписи.
Работа с Narrator/NVDA, переключателями, eye tracking и голосовым вводом на реальном
Windows не проверена. Такие проверки — следующий отдельный этап, а не готовая функция.

6. ЧТО ДЕЛАТЬ ПРИ ОШИБКЕ

Git не найден: установи Git и перезапусти launcher.
Tkinter не найден: нужен Python с Tcl/Tk.
Библиотека внутри репозитория: выбери другую папку.
Ничего не отправляется в AI: это ожидаемо, доступен только ручной handoff.
Каталог уже существует: «Обновить (F5)» или «Открыть снимок…».
Ошибка экспорта: прочти диалог и manifest; незавершённый каталог не считать готовым.
Большой репозиторий: сбор идёт в рабочем потоке; файлы дерева добавляются порциями.
Закрытие во время работы может прервать операцию. Сначала дождись завершения.

7. ЧТО НУЖНО ДОРАБОТАТЬ ДЛЯ АВТОМАТИЗАЦИЙ

Следующий контур: реестр доступных команд репозитория → безопасный план →
локальный исполнитель с журналом и остановкой → импорт результата → независимая
проверка → следующий шаг. Все команды нельзя безопасно выводить из имён функций:
нужны конкретные входы, окружение, границы побочных эффектов и критерии результата.

Laya требует проверки установленной версии, схемы импорта и реального адаптера.
Голос — будущий вход в тот же контракт задач. ChatGPT/Grok/Gemini — будущие адаптеры
передачи и получения, с привязкой к нужному чату. Подтверждение merge требует факта
из Git/GitHub; фраза пользователя «потом будет merged» — ожидание события.
Код из контекста или ответа AI не становится командой для автоматического исполнения.

Проверки этой поставки: syntax/import и headless-контракты описываются в общем отчёте.
Реальный Windows, экранный диктор, установленная Laya и внешние AI-аккаунты не тестировались.
