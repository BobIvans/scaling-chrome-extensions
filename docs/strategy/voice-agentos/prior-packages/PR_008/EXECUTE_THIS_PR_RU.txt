Реализуй минимальные функции:
- Native durable.info: version/capabilities/byte budgets/profile/store/backend
  identity; metadata query без создания Core/DB и без выполнения jobs.
- --desktop-stdio mode для того же installed native_adapter; versioned reply
  содержит actual loaded-profile binding от объекта, использованного dispatcher.
  Browser legacy mode/dispatch(request, profile_path) остаётся совместимым.
- Desktop client принимает только read allowlist, запускает configured Python +
  installed adapter + operator profile через argv/shell=False, отправляет один
  UTF8 JSON + EOF. stdout/stderr читаются совместно с общим byte budget.
- Timeout/close: stop child, reap, close pipes; UI остаётся отзывчивым.
- Strict reply/schema/operation/profile identity; requestId и generation fence
  локально связывают child и UI. Late replies не меняют новое окно/namespace.
- Tkinter UI: настройки подключения, версии/путь данных, namespaces, search,
  выбранные items → bounded context → TASK_DRAFT.txt + metadata JSON.
- Поиск обозначен top matches; selected context не выдаётся за весь repo.
  Existing inventory paging проходит до EOF, только если API объявлен backend.
- Launch_Windows.ps1 + preflight к имеющемуся runtime/backend. Shell uninstall
  сохраняет backend, profile и corpus. Не требуются Chrome/extension ID/Node/
  Codex для этого direct-Python route; existing browser installer не заменять.
