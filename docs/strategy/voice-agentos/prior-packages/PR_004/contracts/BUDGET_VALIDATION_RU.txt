Budget JSON проверять strict schema, integer без bool, ranges и relational
checks: retained stderr ≤ total; read block × queue blocks ≤1 MiB. RSS target
fields — критерии device qualification, не observed measurements и не механизм
OS enforcement. Fixture generator имеет предел параметра 500,000 для размера
синтетического test dataset; это не лимит application corpus.
Batch flush выполняется по rows или normalized bytes, что наступит раньше. Один record обязан поместиться в byte budget; иначе explicit RECORD_LIMIT.
