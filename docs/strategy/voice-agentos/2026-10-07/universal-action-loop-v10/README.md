# Universal Action Loop V10

Target runtime:
`Goal → Observe → Discover capability → Choose route → Execute → Reobserve → Verify → Recover → Learn`

Fallback:
`registered capability/API/WebMCP → CDP/DOM/AX → qualified site adapter → Windows UIA/native → screenshot/vision action proposal → human`

Current runtime is not yet universal computer-use. V10 defines the missing fallback contract.
