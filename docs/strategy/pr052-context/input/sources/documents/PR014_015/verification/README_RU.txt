Проверка документационного пакета: python scripts/validate_package.py из распакованного ZIP. Скрипт использует stdlib, проверяет весь manifest, hashes preserved source files, exact criteria cardinality/text, case mappings, 10 positive schema examples и unexpected-field negatives, contiguous 1001-part fixture, links, full backlog 160/164 и task dependencies.
Это bounded validator для применяемых type/properties/required/additionalProperties/enum/minimum/maximum/pattern/minLength/minItems/items. Он не является полной реализацией JSON Schema, JCS, application handlers, migrations или backup engine. Runtime semantics проверять actual owner tests. Structural-valid placeholders не wire verified.
MANIFEST.json и verification/PACKAGE_VALIDATION.json исключены из самохэширования; все остальные файлы полностью перечислены. ZIP CRC проверяется отдельно после сборки. Package result PASS не меняет OPEN/NOT_RUN для приложения.
