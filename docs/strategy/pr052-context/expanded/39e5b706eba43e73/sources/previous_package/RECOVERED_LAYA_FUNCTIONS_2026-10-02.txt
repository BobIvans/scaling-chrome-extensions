The key architectural idea is that **Laya owns the state, not ChatGPT, Claude, Grok or any other model**. A request such as:

> “Continue our Flashloan bot. Find everything we discussed but never implemented, check what new research appeared this week, compare it with the current repository, test promising ideas in paper mode, and prepare the safest useful PR.”

would become:

**Voice → Intent → Goal → Memory retrieval → chat-history retrieval → repository retrieval → current web/X research → planner → parallel specialist agents → sandbox execution → verifier → approval → PR → updated persistent memory.**

That gives you most of the *product behavior* people want from a persistent 24/7 agent without making the application dependent on whether ChatGPT itself exposes that feature in the EU. The AI provider becomes replaceable infrastructure; **Laya becomes the persistent agent.**
