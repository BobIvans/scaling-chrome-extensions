ТЕРМИНАЛ, VS CODE И WEB3

СЕЙЧАС В ПРОТОТИПЕ
Для snapshot папки есть кнопки открыть VS Code и PowerShell в исходном каталоге.
ZIP никогда не становится исполняемым проектом автоматически. Кнопки не запускают
команды из содержимого файлов/ответа AI. Windows execution пока NOT_RUN.
Терминал текущего ChatGPT Work находится в отдельной среде: desktop-приложение
не получает к нему доступ само собой. Нужен отдельный подключённый local bridge/MCP
или выбранный локальный coding client. API key не даёт доступа к Dell автоматически.

ЦЕЛЕВОЙ REGISTERED EXECUTOR
TaskSpec → действие из registry → workspace/SHA binding → argv array → process
supervisor → stdout/stderr artifacts → exit + independent postcondition → receipt.
stdin/stdout streams ограничиваются порциями, полные логи сохраняются на диск.
Run ID, process identity, cancellation и restart reconciliation нужны для повторов.
Одновременные чтения допустимы; один writer на Git worktree. Patch не применяется
к другой базе. Секреты предоставляет credential broker; в context они не входят.

ПОРЯДОК FLASHLOAN
1. Импорт актуального studious-pancake repo и выбранных logs/docs/CI receipts.
2. Карта entrypoints/config/стратегий/transport/lifecycle/tests и реальных blockers.
3. Завершение code review + targeted fixes через отдельный worktree.
4. qualification.inspect/qualify_and_report через действующий domain contract.
   В прошлом пакете указан scripts/run_occ_memory_qualification.py; перед
   интеграцией повторно проверить текущий repo, SHA и аргументы, не угадывать их.
5. Paper/replay supervisor: данные, конфигурация, start/stop/status, receipts.
6. Отдельная live-ready оценка и явно заданная политика финансовых действий.
В этом ZIP сделки не отправлялись и bot runtime не запускался.

WEB3 DATA LIBRARY
Сырые observations + provider + chain + market/pair + timestamp/slot + fetch time
+ unit/decimals + quality flags. Нормализация сохраняет исходники.
Связать research idea → hypothesis → dataset snapshot → simulation/paper run
→ costs/failures → decision → code revision. Измерять data freshness и gap coverage.
Laya может распределить research tasks, но execution validity проверяет bot runtime.

ПОЛЕЗНЫЕ ПЕРВЫЕ КНОПКИ
Собрать контекст блокера; проверить требования; подготовить patch request;
открыть рабочую копию; показать результаты тестов; импортировать qualification;
подготовить paper plan. Кнопки запуска появляются только для зарегистрированных
и проверенных adapters. Никакой произвольный AI JSON не создаёт новую command authority.
