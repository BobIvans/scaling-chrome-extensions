SCE DESKTOP CONTEXT — РАСШИРЕННЫЙ ПАКЕТ, 03.10.2026

Цель: загружать ZIP/папку репозитория, сохранять полные пути и исходные байты,
вести локальную библиотеку, передавать проверяемый контекст в AI и продолжать
разработку studious-pancake. Chrome для приложенного прототипа не нужен.

БЫСТРЫЙ ЗАПУСК НА WINDOWS 11
1. Распакуйте этот ZIP в постоянную папку, например C:\SCE-Desktop.
2. Нужен Python 3.11+ с Tcl/Tk. Проверка: py -3 -m tkinter.
3. Дважды нажмите START_DESKTOP.cmd. Или: py -3 app\desktop.py.
4. Выберите пустую/новую папку библиотеки, например C:\SCE-Library.
   Она должна быть ВНЕ папки импортируемого репозитория.
5. Импорт ZIP / файлов → выберите свой ZIP около 4 MB.
6. Выберите snapshot. Поиск работает по пути и тексту. Страницы по 200 строк
   нужны только для UI: число документов и полный экспорт ими не ограничены.
7. Нажмите Экспорт ВСЕГО snapshot. Выберите папку назначения и размер TXT-части
   в БАЙТАХ. По умолчанию 200000. Это не количество токенов.
8. В результате: index.json, files.jsonl, context_00001.txt… и originals/.
   Все части по порядку составляют единый текст с metadata boundaries.
9. Передайте AI index.json и нужные context_*.txt. Для последовательного полного
   review используйте docs/07_AI_REVIEW_PROTOCOL_RU.txt и ledger.

ЧТО РЕАЛЬНО ЕСТЬ В ЭТОМ ZIP
Рабочий исходный Python-прототип: desktop UI, ZIP/папка/файлы, SQLite FTS,
content-addressed originals, сохранение путей/дубликатов, страницы текста,
теги/заметки, полный экспорт, STOP и resume ZIP, разбор ChatGPT conversations.json
на user/assistant messages, открытие VS Code/PowerShell и одно явное API-сообщение.
Импорт и упаковка не требуют AI. Pip-зависимостей у прототипа нет.

СОСТОЯНИЕ ПРОВЕРКИ
Локальные unit/integration проверки на Linux — evidence/TEST_RESULTS.txt.
Windows GUI, кнопки VS Code/PowerShell, реальный OpenAI API и Laya inference —
NOT_RUN. Это исходный прототип, не подписанный .exe и не production-ready релиз.
Репозитории GitHub не изменены. Реальный ZIP studious-pancake здесь не приложен:
проверка на синтетическом ZIP >4 MB не является аудитом вашего бота.

ГРАНИЦЫ ПОЛНОТЫ
Оригиналы хранятся отдельно от текстовых производных. Бинарные файлы, неизвестные
кодировки, архивы внутри архива, PDF/DOCX/аудио могут иметь RAW_ONLY — оригинал
сохранён, содержимое не объявлено прочитанным. Ошибки не превращаются в SUCCESS.
Прототип не читает историю из аккаунтов: импортируйте собственные экспорты.
Найден один сохранённый Grok-разговор (18 сообщений, 9 пользовательских),
прошлый SCE-пакет и Laya R&D V2, а также фрагменты более ранней истории.
Это не все сообщения пользователя во всех чатах.
