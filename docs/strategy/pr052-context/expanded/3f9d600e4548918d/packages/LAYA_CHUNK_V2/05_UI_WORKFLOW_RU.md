# UI workflow

Любой chunk показывает source, full content, dependencies, tests, PRs, chats, freshness, qualification и history.

Quick actions:
`ADD TO CART · ASK · COMPARE · FIND MISSING · FIX · IMPLEMENT · TEST · QUALIFY · RESEARCH · CREATE AUTOMATION`

Voice example:
“Собери всё по FAST-Q1, что ещё блокирует qualification.”

Laya resolves project → finds FAST-Q1 chunks → expands evidence/dependency graph → excludes superseded → adds current truth → creates visible Context Cart.

Context Cart → Build Pack → Codex/ChatGPT/Grok/Gemini/local → result import → verification → receipt → Library update.
