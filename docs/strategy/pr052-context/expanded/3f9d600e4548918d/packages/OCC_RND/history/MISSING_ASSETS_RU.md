# Неполученные источники — явно, без фиктивной агрегации

В этой сессии не были доступны как реальные файлы прежние архивы, упоминаемые в истории, например:

- `OCC_CONTEXT_STUDIO_300K_RU_2026-10-02.zip`
- `OCC_FIRST_DOCUMENT_TO_CHATGPT_RU_2026-10-03.txt`
- `STUDIOUS_SCE_FULL_CONTEXT_RU_2026-10-03.zip`
- старые OCC/LAYA/Voice/Wave ZIP и docs из предыдущих чатов.

Их имена не означают, что содержание вложено в этот ZIP. Прежние заявления о 38 MB/числе томов/тысячах файлов или static signals не используются как свежие измерения.

Также отсутствуют полный export аккаунта ChatGPT, локальные Telegram media, твой filesystem, исходники всех прежних generated artifacts, полные checkout обоих repo и live результаты на Dell.

Пакет содержит способы локально получить/импортировать эти данные; actual acquisition требует доступных исходных байтов. Manifest обязан показывать MISSING_SOURCE/ATTACHMENT_UNAVAILABLE до их появления.
