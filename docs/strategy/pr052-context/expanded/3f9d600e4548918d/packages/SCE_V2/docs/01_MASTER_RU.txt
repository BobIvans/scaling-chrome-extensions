КАКОЕ ПРИЛОЖЕНИЕ СТРОИМ

Локальное рабочее пространство на Dell Windows 11 для файлов, заметок, истории,
кода, целей и результатов. Библиотека даёт хранение и поиск как файловый сервис;
страницы, теги, связи, таблицы и представления дают удобство рабочей базы знаний.
Контекст-пакеты и проверяемые действия связывают её с ChatGPT и web3-проектом.

АКТУАЛЬНОЕ РЕШЕНИЕ ПОЛЬЗОВАТЕЛЯ
Chrome extension и Native Messaging перестают быть обязательной точкой входа.
Главный клиент — desktop. Browser capture может стать необязательным источником.
Нужен импорт всего ZIP около 4 MB с полными путями; ограничения 20 документов,
2.2 MB, 300 ZIP entries и 8 MiB не должны определять объём библиотеки.
Первая цель — агрегировать контекст и передавать его AI. Запуск бота — следующий
контролируемый этап; текущий запрос не является командой отправлять транзакции.

ТРИ РАЗНЫЕ ПОЛНОТЫ
1. Сохранность: исходный файл/архив записан и совпадает SHA-256.
2. Извлечение: какие форматы и участки реально преобразованы в текст.
3. Анализ: какие источники реально вошли в запросы и получили review.
Эти счётчики отображаются отдельно. 100% первого не означает 100% второго/третьего.

ЦЕЛЕВАЯ ЦЕПОЧКА
Источник → оригиналы → индекс → контекст задачи → AI/Laya proposal → action
registry → исполнитель → независимое наблюдение → receipt → обновление памяти.
Сохранённый текст источника не изменяет права исполнителя.

ПОЧЕМУ НЕ ОДИН ГИГАНТСКИЙ PROMPT
Хранить можно весь corpus, но отдельные модели имеют свои окна и тарифы.
Для архива даём полный экспорт. Для решения задачи — выбранный snapshot,
зависимости, требования, известные решения и недостающие части. Полный review
проходит через ledger частей и отдельную сводку межмодульных проблем.

ПРИОРИТЕТ ПО ПОЛЬЗЕ
Сначала надёжный импорт и экспорт; затем память собственных целей и соответствие
требование→код→тест; далее AI roundtrip и проверки результата; после этого
автоматические эксперименты и paper/qualification supervisor.
Метрики: время до воспроизводимого контекст-пакета; доля учтённых файлов;
число потерянных путей; ложные DONE; повторная работа; стоимость verified task.
Число PR, агентов или функций само по себе не является достижением цели.
