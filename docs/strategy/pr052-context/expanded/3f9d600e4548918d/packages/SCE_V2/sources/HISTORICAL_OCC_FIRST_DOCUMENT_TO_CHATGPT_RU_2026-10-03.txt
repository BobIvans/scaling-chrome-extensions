КАК ДАТЬ ДОСТУП
Приложи этот документ к ChatGPT/Codex и укажи два GitHub repo. Подключение
GitHub даёт только фактически предоставленные connector permissions: проверь
read/write и наличие выполнения тестов. Для Windows нужен установленный local
native host с operator profile и выбранными директориями. Текст документа
не устанавливает host, не выдаёт OAuth scope и не открывает весь диск.
API credential хранится локально в предназначенном secret mechanism, не в
документе, ZIP, Git, browser content script или model prompt.
На первом этапе paid_api_budget=0: архивирование и тесты работают локально.
