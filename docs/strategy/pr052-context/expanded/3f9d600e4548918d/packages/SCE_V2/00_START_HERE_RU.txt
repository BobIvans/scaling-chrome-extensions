SCE DESKTOP CONTEXT — R&D V2 / 03.10.2026

Распакуйте ZIP в новую папку. Нужен Python3.11+ с Tcl/Tk. Сторонних pip-зависимостей для поставляемого прототипа нет.
Запуск Windows11: START_DESKTOP.cmd. Папку библиотеки выберите вне репозитория.
Импорт ZIP/папки → Экспорт ВСЕГО snapshot → новая кнопка «R&D: разметка / контекст цели / code smells / evidence».
R&D-инструменты можно открыть отдельно: START_RND_TOOLS.cmd.

Первые действия:
1. Импортируйте собственный ZIP или папку. Оригиналы и полные пути сохраняются; бинарные неподдержанные форматы отмечаются RAW_ONLY.
2. Для ChatGPT conversations.json выберите запись и «Разобрать ChatGPT JSON». Экспорт учитывает все mapping branches.
3. Экспортируйте context pack. В R&D нажмите «Разметить context pack». Задайте стабильный namespace (например flashloan), одинаковый для следующих версий того же repo.
4. Нажмите «Контекст по цели». Это лексический подбор кандидатов; включение всего текста доступно отдельным флажком. Читайте coverage.jsonl и report.json.
5. Для Python проекта запустите «Python code smells» и сохраните JSON вне проекта. Исходный код не исполняется.
6. «Проверить receipts» принимает план, корень артефактов и receipts. Это проверка предоставленных данных; происхождение runner ещё не криптографически удостоверяется.

СТАТУС
Реализованы офлайн CLI, запускающее их окно и прежний desktop prototype. Windows GUI ещё не проверен на Dell.
Новые JSON с .SPEC.json не являются исполняемыми recipes. Старый app/run_recipe.py принимает только прежний import→export рецепт.
Настоящие ASR/Laya/Grok/browser/updater/bot integrations — SPEC/NOT_RUN. Они не включаются от распаковки ZIP.
Никаких авто-merge, платных provider-запросов, отправки транзакций или бесконечного прослушивания эта поставка не запускала.

ОГРАНИЧЕНИЯ
Архив не ограничен20 документами; модели и RAM имеют реальные пределы. No silent loss означает явные состояния и остаток работы, а не бесконечную память.
Некоторые индексные структуры/AST/JSON загружаются в RAM; экстремально большие источники требуют следующего этапа streaming/storage R&D.
Разметка хранит ссылки на originals в export pack — не удаляйте его после labeling. Изменения source/labels могут инвалидировать контекст.
Резкое STOP дочернего CLI может оставить временную папку; наличие временных файлов не означает COMPLETE. Читайте итоговый manifest/report.
Прототип использует отдельный desktop-prototype.sqlite3. Производственную интеграцию выполнять через существующие SCE owners/store/queue.
