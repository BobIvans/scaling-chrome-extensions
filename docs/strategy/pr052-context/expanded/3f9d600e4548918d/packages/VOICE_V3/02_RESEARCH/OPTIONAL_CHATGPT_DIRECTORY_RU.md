# Неотвеченный вопрос об иконке/ссылке на сервис

Точную иконку из прежнего сообщения идентифицировать нельзя: её изображения и названия в доступном контексте нет. Её появление не доказывает связь с ранее обсуждавшимися личными идеями.

Текущая официальная документация OpenAI [S17] описывает plugin directory: пакет с MCP connections и/или skills, validation, review и publication. Страница Apps SDK submission при проверке перенаправлялась на Plugins submission. Поэтому просто вставить service URL или подключить личный connector не значит автоматически сделать сервис доступным всем.

Для личного desktop AgentOS публикация вообще не обязательна. Сначала local-only библиотека и выбранные AI adapters. Будущая публичная интеграция — отдельный review/security проект с минимальным scoped API. Не открывать общий терминал или всю локальную библиотеку публичному endpoint.

Ни аккаунт/план пользователя, ни региональная доступность конкретной иконки здесь не проверены. Публикация/регистрация не выполнялись.
