ЧТО НОВОГО В ЭТОЙ ВЕРСИИ
Эта версия расширяет сохранение и перенос стратегии. Runtime приложения не менялся.
Полные прежние пакеты находятся в packages/, их исходные ZIP — в original_archives/.
Новые слова, индексы, идеи и handoff расположены в 01_…04_. Полный объединённый
текст доступен в ALL_CONTEXT.txt; ORIGINALS остаются основой для бинарных данных.
Размер частей ALL_CONTEXT_PARTS регулирует перенос, а не обрезает общий объём.

ЗАПУСК ПРЕЖНЕГО DESKTOP-ПРОТОТИПА
Распаковать весь архив в отдельную папку. Для сохранённого Python-прототипа нужен
Python 3.11+ с Tcl/Tk; исходная инструкция — packages/SCE_V2/00_START_HERE_RU.txt.
На Windows открыть packages\SCE_V2\START_DESKTOP.cmd.
Отдельное окно R&D: packages\SCE_V2\START_RND_TOOLS.cmd.
Этот архив не является проверенным установщиком Windows. Проверка на Dell и
подключение реальных ASR/Laya/Grok/browser/bot adapters остаются будущими этапами.

ВАЖНО ДЛЯ ПРОДОЛЖЕНИЯ
Сначала сохранить полный контекст и сделать один полезный работающий цикл.
Дальше — связать его с существующими owners SCE и актуальным bot repo.
Не начинать заново тысячу задач и не выдавать количество JSON за готовую систему.
Задачи live, внешних изменений и новых доступов требуют отдельного конкретного
задания; сохранённые обсуждения таких возможностей не запускают их автоматически.
