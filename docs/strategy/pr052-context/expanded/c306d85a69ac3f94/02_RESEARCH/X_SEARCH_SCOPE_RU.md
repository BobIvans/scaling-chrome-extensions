# Что получилось проверить по X/Twitter

3 октября 2026 выполнены web-поиски по Laya, Jev, TypeSafe и переходы к X-ссылкам в статье авторов интеграции LangChain [S21]. X search и прямые страницы этих постов вернули ошибки/непригодные результаты. Надёжный набор прочитанных X threads не получен.

В [S21] есть ссылки на browser-agent демонстрацию, email triage и trading demo. Здесь не утверждается, что сами посты или исходный код всех этих демонстраций прочитаны; trading demo не является evidence прибыли или безопасности нашего бота.

Техническую часть подтверждают прочитанные первичные документы Laya, TypeSafe, LangChain и runtime repositories. Нельзя писать «все на X уже так делают» либо выводить success rate из лайков. Социальные ссылки — discovery leads, а не execution receipts.

Для будущего модуля social research: public URL → source snapshot → author/event date → claim → linked original code/paper → checked revision → reproducible experiment. Недоступный пост хранить как UNAVAILABLE, а не заменять придуманным пересказом. Этот модуль не обходит авторизацию и не делает авто-публикации.
