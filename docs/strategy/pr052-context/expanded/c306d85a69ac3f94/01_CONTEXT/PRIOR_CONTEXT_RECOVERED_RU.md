# Контекст прежних обсуждений, найденный при сборке
30 сентября–3 октября обсуждались локальная библиотека вместо обязательного Chrome extension, весь repo с сохранением путей/источников, автоматический refresh, голос → typed proposal → registered action, один durable control plane, voice/Laya как DATA_ONLY, и Studious как владелец qualification.

Сохраняемые решения: не заводить второй competing content.sqlite или queue owner; не считать CI/fixtures доказательством live market execution; ранее предложенные функции и PR-статусы повторно проверяются перед применением.

Сегодняшние найденные пересказы называют другие ZIP-пакеты и результаты тестов. Их оригиналы в этом выполнении отсутствуют. Их размеры, количества файлов и статусы merge не перенесены в список проверенных фактов нового пакета.

Текущий документ — синтез извлечённого контекста, не полный архив личной истории. Для дальнейшего полного импорта предусмотрен coverage manifest с unknown/missing entries.
