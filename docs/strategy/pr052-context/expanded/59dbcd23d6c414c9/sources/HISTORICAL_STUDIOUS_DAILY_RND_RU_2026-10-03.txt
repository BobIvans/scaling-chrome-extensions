ID: SPG-01-PUBLIC-IDENTITY-INPUT; прежняя цель SPG-01.
Repo: BobIvans/studious-pancake.
Base: 67d3852cbc4cb1b24582df45adbf6a42d4da2af0.
Owner: src/qualification_report.py; CLI src/automation_cli_pr189.py;
валидация src/config/runtime.py и существующий validate_pubkey.
Изменение: один optional operator-owned public identity input; нормализованный
адрес включить в input_digest и передавать ребёнку только после валидации.
Не расширять наследование environment, не менять provider/signer/sender policy.
OCC должен впоследствии использовать тот же проверенный контракт и существующий
bridge; добавлять второй executor или автоматически править оба repo не требуется.

Приёмка
1. Valid public identity reaches the child through the explicit input; a unit-test address is marked fixture, never user wallet or market evidence.
2. Malformed identity fails existing canonical validation before subprocess creation; no arbitrary environment passthrough.
3. Changing normalized identity changes input_digest; reusing request_id with another identity produces REQUEST_ID_INPUT_CONFLICT.
4. Secret reference, RPC URLs, provider credentials, signer and sender remain unavailable; MarginFi remains disabled.
5. Absent identity preserves the honest BLOCKED outcome; one supplied address does not invent the missing atomic/fee/lender/Jupiter bindings.
6. Existing qualifier and CLI focused regression checks pass on actual changed head; installed receipt is a separate requirement, not inferred from tests.
7. qualified=false, release_authorized=false, live_authorized=false, transactions_sent=0 remain invariant.

Доступные входы: pinned source, свежие SHA, текущие CLI/WalletConfig, исторический
installed receipt, текущий pure-function probe. Отсутствуют registered writer,
operator profile, выбранная публичная идентичность и квалифицированные зависимости
для настоящего установленного paper опыта. Фикстура адреса допустима в unit test,
но не как подмена пользовательского входа для получения READY.
Limits: provider budget=0; writers=1; attempts≤3; send_transactions=false;
signer_access=false; auto_merge=false; push/PR/deploy запрещены в этом задании.
Stop: SOURCE_DRIFT, PUBLIC_IDENTITY_INVALID, MISSING_OPERATOR_PROFILE,
REQUIRED_TEST_FAILED, UNEXPECTED_NETWORK_OR_SIGNER_ACCESS, UNKNOWN_EXTERNAL_OUTCOME.
Для code job нужен свежий наблюдаемый usage bucket. Нужного authenticated app-server
или official UI capture здесь нет: actual quota UNKNOWN, model jobs не допущены.
