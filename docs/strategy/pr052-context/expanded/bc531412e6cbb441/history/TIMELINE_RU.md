# Восстановленная история идей

**Область достоверности:** поиск персонального контекста вернул summaries, не полные дословные transcripts. Названия чатов и тексты недоступных вложений не выдумываются. Здесь нельзя утверждать, что найдены ВСЕ старые сообщения. Даты ниже относятся к найденным обсуждениям; диапазон означает агрегированную тему.

## 2024-02-20
**Твоя идея, пересказ:** Личные записи жизни в приватных Telegram-каналах: голос, видео, текст; автоматическая копия в Notion через Colab.

**Предыдущая идея ассистента, пересказ:** Telegram API → Python в Colab → Notion API; пагинация, аутентификация и плановый запуск.

**Что перенести сейчас:** Первый известный корень archive-of-anything. Сейчас заменить Colab-зависимость локальным durable ingest с source rights.

## 2026-08-06
**Твоя идея, пересказ:** Colab XFCE/Chrome/noVNC, Drive persistence, запуск одной ячейкой и кнопка сохранения.

**Предыдущая идея ассистента, пересказ:** Архив chrome-profile.tar.zst на Drive для восстановления среды.

**Что перенести сейчас:** Переносимость рабочей среды полезна, но browser cookies/session data исключать из AI context и обрабатывать как чувствительные.

## 2026-09-14
**Твоя идея, пересказ:** Сравнение Spark4B и 12B для web agent/extension/GitHub/Studious/Web3.

**Предыдущая идея ассистента, пересказ:** Маленький локальный быстрый router + отдельный более сильный reasoning/coding слой; кеширование runtime/model.

**Что перенести сейчас:** Исторический model split. Конкретные старые имена моделей требуют новой проверки; избежать постоянной загрузки многих моделей.

## 2026-09-19
**Твоя идея, пересказ:** Продолжение объединённой базы контекста и разработки.

**Предыдущая идея ассистента, пересказ:** Notion как журнал архитектуры/PR/решений, Drive как архив, локальный Dell как router/LLM.

**Что перенести сейчас:** Разделить original storage, knowledge projections и execution state; не сделать три несогласованных owner.

## 2026-09-21
**Твоя идея, пересказ:** Быстро собирать контекст из любых источников, локально и в Notion, записывать голосовые идеи, связать с ChatGPT и конкурировать с Cursor.

**Предыдущая идея ассистента, пересказ:** Voice→Inbox→Project/Topic; Context Shopping Cart; Fresh Chat Handoff; repo snapshots/diffs; failed attempts; evidence packs; portable TXT/MD/JSON/ZIP; MCP.

**Что перенести сейчас:** Наиболее прямой предшественник текущего desktop-проекта. Сохранить как требования, а не повторно придумать очередную волну.

## 2026-09-24
**Твоя идея, пересказ:** Новые Wave/DRS направления Studious и больше исследовательских функций.

**Предыдущая идея ассистента, пересказ:** Point-in-time Web3 Decision Episodes: raw state, routes, uncertainty, counterfactuals и outcomes; continual state, active perception, model parliament.

**Что перенести сейчас:** Outcome dataset полезнее неподтверждённых model votes. Сначала сбор фактических episodes и holdout.

## 2026-09-24
**Твоя идея, пересказ:** Wave15 и последующие направления, новый тип развивающегося интеллекта.

**Предыдущая идея ассистента, пересказ:** Evidence-Service Procurement Arena, institutional digital twin, intent/orderflow compatibility, Market-of-Markets / Intent-Obligation-Evidence Exchange.

**Что перенести сейчас:** Оставить R&D-гипотезами; не считать существующими рынками или реализованными adapters.

## 2026-10-01..2026-10-02
**Твоя идея, пересказ:** Laya JSON, голосовые действия, локальная библиотека, 24h qualification, сбор многих прежних docs и waves.

**Предыдущая идея ассистента, пересказ:** Advisory routing, qualification handoff и evidence-based iterations; mixed historical proposals.

**Что перенести сейчас:** Текущий код проверять отдельно. Готовый JSON без adapter/receipt не означает исполненную кампанию.

## 2026-10-03
**Твоя идея, пересказ:** Отказаться от обязательного Chrome, снять потолок документов, всё сохранить с путями, связать desktop library/VS Code/бот/ChatGPT API.

**Предыдущая идея ассистента, пересказ:** В этом пакете: full-fidelity archive tooling, phased desktop migration, effect-typed capability graph, truth/evidence ledger.

**Что перенести сейчас:** Текущее новое R&D-предложение и проверяемый архивный прототип.

## Как закрыть полноту истории
Импортировать доступные ChatGPT exports с mapping branches и attachments manifests; Telegram export/media; локальные папки предыдущих ZIP; Drive/Notion exports с source IDs. Сохранить originals и receipts. Имена старых ZIP — только ссылки на отсутствующие объекты, пока байты не получены. Не восстанавливать выдуманные цитаты по summaries.
