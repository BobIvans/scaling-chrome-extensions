# OCC Desktop R&D — 3 октября 2026

**Начать с `00_START_HERE_RU.txt`, затем `AI_HANDOFF_RU.txt`.**

Это R&D-пакет для `BobIvans/scaling-chrome-extensions` и связанного `studious-pancake`: проверенные выборочные факты кода, восстановленная история идей, архитектура Windows-библиотеки, экспериментальные задания, JSON-контракты и работающий локальный архиватор.

## Что внутри действительно сделано

В `tools/archive_tool.py` реализованы сбор папки без потолка числа файлов, чтение закреплённого Git-дерева без импорта его кода, хранение исходных байтов, инвентарь всех обнаруженных путей, SHA-256, потоковый экспорт ВСЕГО UTF-8-текста, фрагменты без отбрасывания хвоста, проверка восстановления текста, статический каталог Python/argparse/package.json и импорт всех mapping-веток ChatGPT JSON. Есть тесты и небольшой desktop front-end на Tk.

**Это не полный исходный снимок двух репозиториев и не полный экспорт твоих прошлых чатов.** Через подключённый GitHub прочитаны закреплённые фрагменты и документы; полное скачивание в среду не удалось. Вложения прошлых чатов не были доступны как файлы. Сохранённые в `history` записи — явно помеченные восстановленные summaries, не придуманные дословные сообщения. На ПК полный Git-снимок собирает `windows/Acquire-Repos.ps1`.

## Что не выполнено

Нет commit/PR/merge. Нет запуска твоего бота, реального paper-campaign, торгов, кошелька или подписанта. Нет теста на Dell/Windows, микрофона, NVDA, Laya/Jev, Hugging Face моделей или OpenAI API. JSON workflow-планы не исполняются автоматически. Успешные тесты относятся только к приложенному архиватору и синтетическим фикстурам Linux.

## Приватность прежде передачи в AI

Архиватор **сохраняет оригиналы локально**, включая потенциально чувствительные обычные файлы выбранной папки. Полнота локального архива не означает разрешение отправить его в облако. `possible_secret_name` — слабая подсказка, НЕ полноценный поиск секретов. Не выбирай весь диск и не загружай получившийся raw-архив без проверки. Следующий production-слой должен делать отдельную sanitized-проекцию с журналом исключений и явным разрешением на передачу.
