# Scaling Chrome Extensions

## One Click Context

Локальное расширение Chrome: **открой страницу → нажми значок → вставь текст через Ctrl+V**.

- Выделенный текст копируется без обёрток.
- Переписка или основное содержимое страницы собирается при ограниченной прокрутке.
- Локальный просмотрщик: импорт UTF-8, SHA-256, копирование и скачивание исходного файла.
- Отмена повторным нажатием или Escape во время сбора.
- Без аккаунта, AI API, сервера и автоматической отправки переписки.

### Установка

1. Скачай репозиторий через **Code → Download ZIP** и распакуй.
2. Открой `chrome://extensions`, включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери папку **one-click-context**, содержащую `manifest.json`.
4. Закрепи значок расширения. Горячая клавиша: **Alt+Shift+C**.
5. Для просмотра или открытия TXT: правый клик по значку → **Preview / copy last capture / open TXT**.

### Границы версии 0.2.0

Результат HTML помечается BEST_EFFORT или PARTIAL: полнота истории не гарантируется.
Скрытые, незагруженные сообщения, текст на изображениях и недоступные фреймы могут отсутствовать.
Совместимость с авторизованными ChatGPT, Codex и DeepSeek пока не подтверждена; используются общие семантические признаки DOM.
Копирование последнего ответа и разбиение на части оставлены для следующей версии.

Содержимое хранится в сессии расширения. Очистка не удаляет системный буфер и скачанные файлы.
Личные вложения и контекст торгового проекта в этот репозиторий не включены.
